# Computational verification summary

This summary describes the independently checked computational evidence.
Source versions and exact result hashes are recorded in the tooling source
map. These are the recorded checks, not a claim of a new execution.

## Maintained program and useful repair

The general public rectangular_matrix_invariant_count API and CLI count every
SL_p times SL_q invariant component at entry grade lcm(p,q)t, with independent
Weyl profile sets and full pairing. The reviewed weighted-table kernel is
shared with the square API, whose original elementary cases, size/stretch
exchange, work accounting, local caches and JSON behavior are preserved.
General scalar counting does not assert a general rectangular LR constructor
or degree theorem. Forty-two targeted square/rectangular tests pass.

Thirteen matched scalar tasks give 26 agreeing old/new measurements, including
the retained square and rectangular prototypes. Three independent bare LR
controls agree at p2/t1, p2/t2 and p3/t1: 20, 148 and 266. The new general API
primarily extends supported scope; no universal speedup is claimed.
