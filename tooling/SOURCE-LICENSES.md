# Source, verification and licensing

The maintained implementation lives in the research repository's
`code/ehrhart/src/slr_ehrhart/`. This directory is a versioned publication
projection. The repository's `SOURCE-MAP.json` records source commit, path,
source hash, included hash and any packaging transformation for every included
mathematical source file.

The transport, strip and certificate implementations were written in Chris's
research workspace with Codex assistance from the independently verified
mathematics. They do not execute or import returned provider programs. The
native chart oracles in the tests retain exact selected function bodies from
the Fable research lane, with the small standard-library import wrapper needed
to run them independently. Running those oracles here is a comparison against
native source; it does not claim native deployment of this tool version.

The conventional hive implementation, skew-content construction, matrix counter
and conditional support planner retain their source provenance. The new Cdagger
data is a sparse, value-preserving projection of the previously verified full
certificate: every domain row and all thirty-six implications are included,
while operational paths, process receipts and research-session history are
excluded. The standalone verifier reconstructs the complete hive matrix and
rechecks the integer chart and every implication.

The mathematical antecedents are the LR hive/tableau correspondence, network
flows and total unimodularity, the transportation Minkowski criterion,
rising-binomial identities and the stated whole-polytope constructions. The
notes separate these premises from computations and from unproved global
extensions. Algorithmic independence, different count models and separate
reviewers are different forms of evidence; none is human peer review or a
historical novelty claim.

The code imports Python's standard library. No third-party implementation or
new dependency is vendored by this update. The optional existing Sage hooks
in `hive.py` are not used by the standalone examples or checks.

This initial update remains in the existing private repository. It selects
no new public license and changes no existing licensing or authorship decision.
Public licensing, public release and collaborator invitations remain decisions
for the repository owner. Source notices are preserved; model assistance is
disclosed without assigning models human authorship.
