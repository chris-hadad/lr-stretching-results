# Complete-object release tests and their scoped nulls

This experiment tests ordinary-positive differences between entire LR polynomials. If whole
integer charts admit H_A(t) contained in H_B(t) at every physical stretch,
order every old integer row ell_j>=0. The exact disjoint partition of the
difference has all B constraints, every preceding A row nonnegative, and
ell_j<=-1 at the first violated row. This keeps simultaneous releases and all
endpoints. It proves a complete count identity for P_B-P_A, not its ordinary
coefficient signs. Those signs need an additional complete argument.

The first degree-six test uses the 256 independently verified sextics, identical
saturated coordinate labels, and normalized-row domination. A B row is implied
by an A row of the same primitive normal when its constant is no smaller.
This finite grammar checks all 65,280 ordered distinct parent pairs and admits
zero inclusions. No auxiliary negative coefficient is observed, because no
whole difference passed the premise check. This is not nonexistence of an
ordinary-positive release operation or of another chart identification.

A material representation repair uses complete row-word models. Delete empty
rows and clip inactive gaps by the proved whole-count normalization map, retaining row lengths,
content and every ballot condition. For two models with the same ordered row
lengths and content, componentwise gap enlargement relaxes only full column
cuts and hence gives an entire real/integer inclusion by identity on row words.
All column cuts can again be partitioned by their first violation. Tensor
identities preserve the entire parent polynomial; the difference is not
assumed to have its own LR realization.

Across all declared padded-six/seven tensor variants of the same 256 parents,
there are 3,048 distinct (parent, row-length, content, gap) models and 2,995 row/content
families. Only 40 cross-parent ordered pairs share row lengths and content, and
none has the required gap dominance. Therefore this repaired grammar also
admits no edge. All rosters, original nulls and the corrected import-path failure
remain in DATA/U05/release-graph and release-rows-v2. No new coverage, universal
monotonicity theorem or terminating positive-difference generator is claimed.

A possible construction starts from a legal source with a strictly positive
active gap and increases that gap while retaining row lengths/content and the
box. Strict pre-existing adjacent lambda/mu gaps preserve their zero-equality
pattern under such a release, offering a controlled degree-bound regime.
The proposed construction requires every changed column cut and a proof of
full parent membership before the whole difference can be evaluated. The current null is evidence that unrelated
positive panels are a poor source of these coupled pairs, not evidence against
that construction. The equality Horn/gap rewrite is not relabelled as a
positive-difference result.
