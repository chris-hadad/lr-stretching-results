# Complete integer component contraction

The input is an entire U01 hive chart, including every original rhombus after the recorded integer selection inverse and all-stretch tensor normalization. The new counter evaluates a single physical grade. It is not the supplied five-dimensional Fourier–Motzkin counter with a larger array. It retains the original inequalities and uses integer-bound deductions, exact component products and full-state memoization. The dimension guard is fifteen; experimental inputs have coordinate bounds at most twelve.

For c+sum a_j x_j>=0 and valid coordinate intervals, let S be the maximum contribution of all coordinates other than k. If all those maximizing endpoints are finite, every feasible integer point satisfies x_k>=ceil(-S/a_k) when a_k>0, and x_k<=floor(S/(-a_k)) when a_k<0. Repeating these implications cannot discard a feasible integer point. If the full row maximum is negative or a lower bound exceeds its upper bound, there is no point. Missing finite bounds are an explicit refusal, never a supplied artificial box. The initial all-infinite intervals receive bounds only from these deductions. No rounded grade-one interval is rescaled to another grade: the complete physical-grade rows are rebuilt first.

A fixed coordinate is substituted exactly. Translating each remaining coordinate by its proved lower bound is an integer bijection to an explicit box 0<=y_j<=w_j. A row whose minimum on the whole box is nonnegative is redundant on that entire box. For a nonzero row with normal gcd g>0, the fixed-grade integer condition c+g*A.y>=0 is equivalent to floor(c/g)+A.y>=0. This last operation is an **integer counting** equivalence, not a real affine or all-stretch polynomial equivalence. Among equal oriented normals the smallest constant is the strongest constraint. Constants, orientation and integer grade remain part of every count state.

Build the incidence graph on the remaining coordinates, joining every pair co-occurring in any retained row. Each connected component contains the whole support of every row assigned to it. Together with the Cartesian coordinate box this proves that the entire integer solution set is the Cartesian product of its component solution sets. Multiply their full counts. When the graph remains connected, fix one integer coordinate in every value of its complete interval and sum the resulting disjoint fibers. A constraint is never discarded merely because its projection looks separated or its marginal count is positive. The recursion terminates by eliminating coordinates. Entire unconstrained boxes contribute the product of widths plus one. Exact integer arithmetic sums and multiplies counts, using Boost's already-installed arbitrary-precision integer header; no dependency was acquired.

The cache key contains the complete remaining width vector, every normalized row and all row constants in their exact coordinate order. Equality of these keys identifies the same fixed-grade integer problem, not merely equal early LR values. The current program resets the cache for each record and physical grade. It does not yet claim a reusable whole-polynomial key or a population-wide speedup.

Work counters, cache bounds, coefficient checks and per-record deadlines provide typed refusals. The first build exceeded a 512-MiB virtual-memory reservation and was retained; the checked retry used a measured 1024-MiB reservation. A deliberate large-coordinate challenge exposed the first implementation's finite infinity-sentinel bug: the unique feasible point (10000,10000000000) was incorrectly treated as outside an empty interval. Version3 refuses any derived bound reaching that sentinel before an emptiness decision. Earlier source, contradictory output and repair tests remain immutable. Only the repaired version is eligible for new acceptance, and pilot observations require independent validation.

The control suite checks complete simplices and boxes through dimension twelve, negative coordinates, a hidden line, emptiness, the non-period-one half interval, and literal enumeration of ninety-six additional complete small H-systems. These are implementation tests, not an LR positivity theorem. The whole LR bridge, prior degree and polynomiality remain the separate authenticated U01/source premises. A negative ordinary vector is persisted before comparison.

This implements the zero-order full-joint-state version of the proposed R5 separator design. It does not yet derive symbolic higher moments, a uniformly small separator for all box members, or an ordinary-positive moving-boundary summation operation. Its structural contribution is an automatically complete component partition of the actual integer constraints, with exact fallback for every coupling that survives.
