# Versions, access and citation

This repository contains selected mathematical proofs, exact data and
verification programs. It is currently private. An immutable link identifies
content; it does not grant a recipient access.

For a reproducible citation, give the repository name, exact Git commit,
module or research-note title and access date. For the finite-box computation,
also name data release `finite-box-2026-09-12-v1` and its
[asset hashes](results/finite-box/DATA-ASSETS.json). The ten numerical data
archives remain unchanged across this documentation update. The earlier
`code-and-proofs.zip` and `complete-offline-kit.zip` in that release contain
the original September 12 source snapshot, not later repository prose or modules.
Use a source archive from the cited commit when referring to this edition.

While the repository is private, a recipient needs access granted by Chris
or an explicitly transferred offline copy. Downloading it through an owner's
authenticated account tests that owner's access only. No external reviewer
access, endorsement or invitation is implied by a successful download.

No open-source or open-content license has yet been selected. Public visibility
would not itself supply a reuse license. The owner will decide the terms for
code, mathematical exposition and original data, and confirm rights for
selected third-party-derived sources described in the source maps. Citation
and credit for prior mathematics remain necessary regardless of that decision.

The research note has no finalized author line. Chris directed the work;
[PROVENANCE.md](PROVENANCE.md) and [METHODS.md](METHODS.md) disclose the substantial
AI contribution and the limits of the verification. Human authorship and
responsibility should be settled explicitly before submitting a paper. Models
are not assigned human authorship here.
